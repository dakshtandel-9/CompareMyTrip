3. Create the website authorization

  1. Configure Google Auth Platform / OAuth consent for CompareMyTrip.
  2. Add https://www.googleapis.com/auth/business.manage as the requested scope. Google uses this scope for reading reviews; this implementation only reads profile data and reviews.
  3. Create an OAuth client of type Web application.
  4. Add this exact production redirect URI:
    https://comparemytrip.in/api/integrations/google-business/callback
  5. For local testing, also register http://localhost:3000/api/integrations/google-business/callback and set that exact value as GOOGLE_BUSINESS_REDIRECT_URI in the local server environment. Restart the local server. Omit this override in production.

If the consent app is in Testing, add the managing Google account as a test user. Testing refresh tokens normally expire after seven days for this scope; finish the applicable Google publishing/verification steps for an ongoing connection. Google’s token expiration documentation.

  3. Choose Load businesses.
  4. Select CompareMyTrip at Old Madras Road, Krishnarajapuram, Bengaluru.
  5. Choose Sync now, then check the homepage cards. Imported comments can be fewer than the total Google rating count because star-only reviews have no written comment.
