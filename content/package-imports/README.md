# Reference package imports

Content transcribed from the two user-supplied PDFs. The JSON files use the same package schema as the editor and preserve the documents' section order.

- **Coorg:** ₹5,643 per person, double sharing, valid through 30 September 2026, subject to availability. Ready for publication.
- **Skandagiri:** saved as a draft because the PDF has no confirmed price or departure date. Set the price in the CMS before publishing.
- Sample testimonials and SEO drafting instructions are omitted. No customer ratings are invented.
- The existing Coorg landscape and Skandagiri photographs are reused. Credits are in `public/weekend-treks/CREDITS.md`. More photos can be added in the editor.

Run `node scripts/import-reference-packages.mjs` to validate and preview, then add `--write` to create the records. Existing IDs are always kept, including any changes made later in the CMS.
